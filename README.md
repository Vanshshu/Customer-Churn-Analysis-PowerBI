# Customer-Churn-Analysis-PowerBI
Interactive Power BI dashboard for analyzing customer churn, retention trends, contract types, tenure, and monthly charges using DAX and Power Query.

## Project Overview

This project is an interactive Power BI dashboard created to analyze customer churn and understand the factors that influence customer retention. The dashboard helps identify customer behavior based on contract type, tenure, monthly charges, and additional services.

The goal of this project is to provide meaningful insights that can help businesses reduce customer churn and improve customer retention strategies.

---

## Objectives

- Analyze the overall customer churn rate.
- Identify which contract types have the highest churn.
- Compare monthly charges between churned and retained customers.
- Analyze customer tenure and its impact on churn.
- Understand how additional services affect customer retention.

---

## Dashboard Features

- Total Customers KPI
- Total Churned Customers KPI
- Customer Churn Rate
- Contract-wise Churn Analysis
- Monthly Charges Analysis
- Customer Tenure Analysis
- Online Security and Backup Service Analysis
- Customer Retention Overview

---

## Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel (Dataset)

---

## Key Insights

- Customers with month-to-month contracts have the highest churn rate.
- Customers with longer contract periods are more likely to stay with the company.
- Customers paying higher monthly charges tend to churn more frequently.
- Customers using additional services such as Online Security show better retention.
- Customer tenure has a strong relationship with churn behavior.
